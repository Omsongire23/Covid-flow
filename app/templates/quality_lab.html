3. STQA Testing Concepts Demonstrated in this Project

Equivalence Partitioning (EP)

Divides input domains into valid and invalid equivalence classes where all members are treated identically by the software logic. Example: For PIN code, 6-digit numbers [100000–999999] form the valid partition, while numbers < 100000 or with non-digits form invalid partitions.

Boundary Value Analysis (BVA)

Focuses on test cases at extreme ends of input ranges. Example: Comment length boundaries tested at 2 characters (too short), 3 characters (min valid), 500 characters (max valid), and 501 characters (rejected).

Selenium 4 Page Object Model (POM)

Decouples web page locators and user actions from test logic, improving test maintenance, reducing test script duplication, and making tests easy to explain in practical examinations.

Server-Side Independent Validation

Client-side JavaScript provides instant user feedback, but the backend Python layer independently parses and validates all requests to defend against CSRF, injection, and manipulated payloads.
